# Hướng dẫn cài đặt dependencies

## Cài đặt package cần thiết

```bash
cd backend
npm install @sendgrid/mail
```

## Giải thích packages

- **@sendgrid/mail**: SendGrid client để gửi email

## Packages đã có sẵn
- ✅ bcryptjs (dùng để hash password)
- ✅ jsonwebtoken (dùng để tạo JWT token)
- ✅ express
- ✅ sequelize
- ✅ mysql2
- ✅ dotenv

## Khởi động server

```bash
npm run dev
```

Server sẽ chạy tại: http://localhost:5000
